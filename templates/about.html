About Accident Risk Predictor

This project was born from the need to democratize road safety analytics. Using a dataset from Kaggle’s Playground Series, we built a robust machine learning model that estimates accident risk on a scale from 0 (very safe) to 1 (extremely dangerous).

How It Works

1️⃣ Input Data

Road geometry, traffic, weather, and time context.

2️⃣ Preprocessing

Scaling, encoding, and feature engineering.

3️⃣ Prediction

Random Forest model outputs risk score.

Key Features

  • ✅ Comprehensive factors – 12 input features including curvature, speed limit, reported accidents, lighting, weather, holiday, school season, and more.
  • ✅ High accuracy – Achieved R² of 0.8828 on validation data.
  • ✅ User authentication – Secure login & registration system.
  • ✅ Instant results – Get risk score in seconds.

Technology Stack

Flask (Python) backend, MySQL for user management, scikit‑learn & XGBoost for ML, and a custom dark theme frontend with CSS animations.

📢 Disclaimer: This tool is for educational and demonstrative purposes. Real‑world safety decisions should always involve expert analysis and local regulations.
